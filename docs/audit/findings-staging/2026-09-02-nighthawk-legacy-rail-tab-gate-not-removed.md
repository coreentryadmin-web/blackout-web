## 2026-09-02 — [FINDING, P2 Night Hawk] Legacy detail rail's reasoning was still tab-gated after a PR that claimed to fix exactly that — FIXED

> **kind:** `FINDING`

| Field | Detail |
|---|---|
| **Symptom** | `src/features/nighthawk/components/LegacyPickLogBoard.test.ts`'s first test (`LegacyPickLogBoard: X Ads shell — table, toolbar, detail rail (Vector parity)`) failed on `main` itself — `assert.doesNotMatch(rail, /VectorBoardDetailTabs/, "legacy rail must show full reasoning on select — not hide it behind desk/timeline tabs")`. `LegacyPlayDetailRail.tsx` still imported and used `VectorBoardDetailTabs`, gating the reasoning panel (`LegacyPlayDetailPanel`) behind a `tab === "desk" \|\| "timeline"` click; row select defaulted to `tab === "overview"`, which shows only four metrics. |
| **Root cause** | PR #3297 ("fix(nighthawk): Legacy detail rail shows full pick reasoning on select") changed only this file's EMPTY-STATE placeholder copy — the "Select a play" text shown before any row is clicked — from a generic description to "Click any row to see why we picked it... full desk reasoning in one scroll." It never touched the actual selected-row markup, which still gated the real reasoning behind the tab click it was supposed to remove. The commit message ("Restore single-scroll detail on select") described the intended fix; the diff (`git show 36f7d1f95 -- .../LegacyPlayDetailRail.tsx`) shows only the copy string changed, 5 insertions / 2 deletions, nothing to the render logic below. |
| **Why not caught earlier** | The same PR added the `assert.doesNotMatch` assertion this bug violates — so the test that should have caught the incomplete fix was introduced red, in the same commit, and evidently `verify` either wasn't checked before merge or the failure was missed. Discovered here only because an unrelated Helix PR's `verify` run surfaced it; ran the exact test against a clean `origin/main` checkout first to confirm it predates and is unrelated to that PR's diff before touching anything. |
| **Fix** | Removed the tab state (`useState<VectorBoardDetailTab>`) and the `VectorBoardDetailTabs` import/render from `LegacyPlayDetailRail.tsx` entirely. The overview metrics grid, `LegacyPlayDetailPanel` (the actual reasoning), and the target-path panel now render unconditionally, together, in one scroll on row select — matching what the empty-state copy already (correctly) promised. |
| **Fix rationale** | Vector's own detail rail (`VectorPlayDetailPanel.tsx`) is untouched — it deliberately keeps its tabbed inspector, and its own test (`VectorPickLogBoard.test.ts`) asserts the OPPOSITE requirement (`assert.match(detail, /VectorBoardDetailTabs/, "detail rail must use tabbed inspector")`). Confirmed via that test before touching anything: Legacy (single-scroll) and Vector (tabbed) are intentionally different UX, not a missed parity case — the "(Vector parity)" in the failing test's name refers to shared table/toolbar/shell components, not the detail-rail interaction model. |
| **Blast radius** | `LegacyPlayDetailRail.tsx` only. Sole consumer is `LegacyPickLogBoard.tsx` (`row`/`onClose`/`sheet` props, all unchanged). No other file imports it. |
| **Gates** | `LegacyPickLogBoard.test.ts` 2/2 pass (was 1/2) · `VectorPickLogBoard.test.ts` 2/2 pass (unchanged, confirms no cross-contamination) · all 76 `src/features/nighthawk/components/*.test.ts` pass · `npx tsc --noEmit` clean · `npx eslint` clean · `node scripts/check-brand.mjs` clean. |
| **Status** | FIXED — PR #3302. |
