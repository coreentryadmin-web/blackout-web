## 2026-11-07 — `endpointTemplate()` never collapses Unusual Whales per-ticker paths (UW cardinality leak) — FIXED

| **Status** | Fixed (PR pending) |
|------------|-------------------|
| **Symptom** | `endpointTemplate()` in `src/lib/api-telemetry.ts` is documented as collapsing "per-ticker / per-OCC paths ... into ONE bounded `endpointStats` entry instead of leaking a permanent entry per symbol (audit 03-BACKEND §3.1)". It does this correctly for Polygon-shaped paths (`/ticker/{sym}`, `/tickers/{sym}`, `/indicators/{fn}/{sym}`, `I:{idx}`, OCC option symbols) but has no rule at all for Unusual Whales paths. Every UW per-ticker route — `uwGetSafe`/`uwGet` call sites in `src/lib/providers/unusual-whales.ts` build paths shaped `/api/stock/{TICKER}/flow-alerts`, `/api/stock/{TICKER}/max-pain`, `/api/darkpool/{TICKER}`, `/api/shorts/{TICKER}/ftds`, `/api/etfs/{TICKER}/in-outflow`, `/api/lit-flow/{TICKER}`, `/api/seasonality/{TICKER}/monthly`, `/api/companies/{TICKER}/earnings-estimates`, `/api/market/{sector-or-etf}/sector-tide`\|`etf-tide`, etc. — pass through `endpointTemplate()` completely unchanged, so each distinct ticker leaks its own permanent `endpointStats` Map entry (keyed `unusual_whales|GET|<raw path>` via `statsKey`). |
| **Root cause** | `endpointTemplate()`'s regex chain only recognizes Polygon's path grammar (`/ticker/`, `/tickers/`, `/indicators/.../`, `I:xxx`, OCC symbols). UW's grammar is structurally different (`/api/<category>/<TICKER>/<rest>`) and none of the existing rules match it — a bare `startsWith`/`includes` check would have caught this at write time, but nothing exercised it: the dedicated regression test (`api-telemetry.test.ts`) only asserted the Polygon shapes, so the gap shipped silently. UW is the busiest fan-out provider in the ring buffer (every desk polls flow-alerts/greeks/darkpool/net-prem/etc. per watched ticker), so this is the worst-case instance of exactly the leak `endpointTemplate()` exists to prevent — not a cosmetic admin-dashboard nuisance but the specific unbounded-cardinality bug audit 03-BACKEND §3.1 was written to close, reopened for one provider. The `MAX_ENDPOINT_STATS` (500) LRU backstop in `recordApiCall` masks the symptom (the Map never grows past 500 keys) but defeats the whole point of templating: distinct tickers' stats evict each other under the LRU, so the admin `/api/stock/:sym/flow-alerts`-style aggregate view never exists for UW, and historical per-endpoint signal (avg/p95/p99 latency, error rate) is lost every time a less-recently-polled ticker gets evicted by a newly-polled one. |
| **Evidence** | `npx tsx --experimental-test-module-mocks --test src/lib/api-telemetry.test.ts` — before the fix: `endpointTemplate("/api/stock/NVDA/flow-alerts")` returns `/api/stock/NVDA/flow-alerts` unchanged (2 new assertions fail, confirmed RED via `git stash` on just `api-telemetry.ts`). After the fix: returns `/api/stock/:sym/flow-alerts`, and a loop of 600 distinct-ticker UW calls (`/api/stock/SYM{i}/flow-alerts`) collapses into one templated `endpointStats` row with `call_count === 600` instead of 600 separate rows, matching the existing Polygon regression test's own methodology one line below it in the same file. |
| **Blast radius** | `endpointTemplate()` is the single shared key-derivation function for `recordApiCall`'s `endpointStats` Map (read by `getApiTelemetrySnapshot()` / `buildEventDetail()` — the admin API-health dashboard's per-endpoint table, latency percentiles, and `diagnoseEvent()` tips) and is called on every one of the ~800-event ring buffer's entries plus every live `recordApiCall`. The fix touches only this one pure function; no caller signature changed. `option-contract` paths are deliberately left out of the new UW rule because their id segment is already collapsed by the pre-existing bare-OCC regex when OCC-shaped — adding a second, less specific rule for that path would have overwritten the more precise `:occ` token with a generic `:sym` one. |
| **Fix rationale** | Added one regex collapsing `/api/(stock\|darkpool\|shorts\|etfs\|lit-flow\|seasonality\|companies)/{ticker}` to `/api/$1/:sym`, plus a second, narrower regex for the two per-symbol `/api/market/{x}/sector-tide`\|`etf-tide` routes specifically (every other `/api/market/...` route — `market-tide`, `top-net-impact`, `fda-calendar`, etc. — takes no ticker segment and must stay untouched; a blanket `/api/market/[^/]+/` rule would have wrongly collapsed those too, which the new test explicitly asserts against). Left every existing Polygon rule byte-for-byte unchanged. |
| **Verify** | `npx tsx --experimental-test-module-mocks --test src/lib/api-telemetry.test.ts` (new assertions pass); `npx tsc --noEmit` clean; full `npm test` run clean (see PR). |
