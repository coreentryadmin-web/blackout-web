# 2026-09-28 Legacy Edition DTE Weekend Gap

> **kind:** FINDING

## Symptom

On a Friday-built Night Hawk Legacy edition targeting the following Monday, certain options contracts expiring Monday ship as "normal swing plays" (with displayed `dte: 3`) when they are actually 0-DTE by Monday morning when members read/trade them.

**Live example (2026-09-28):** MSFT and NVDA both show `dte: 3` while their named contracts expire "Sep 28" — the edition's own target day.

## Root Cause

`pickChainContract()` and `buildPlay()` in `src/features/nighthawk/lib/deterministic-edition.ts` anchor contract DTE calculations on `todayEtYmd()` — the wall-clock build date — instead of the edition's **target trading day** (`edition_for`).

The minimum-DTE filter (`MIN_DTE_CALENDAR_DAYS = 2`) then sees:
- **From Friday (build date):** Monday is +2 days → **PASSES** the filter
- **From Monday (target date):** Monday is 0 days → **FAILS** the filter

A contract that should be rejected (0-DTE, unsuitable for overnight swings) passes the gate and reaches members as a mislabeled play.

**Exact locations:**
- `pickChainContract()` line 282: `const today = todayEtYmd();` — should use `edition_for` instead
- `buildDeterministicEditionPlays()` line 919: calls `pickChainContract()` without passing the edition target date
- Same issue in diversity-hedge Phase 1 (line 1023) and forced-contrarian Phase 2 (line 1063)
- `buildRescuePlays()` line 1162: similar call without edition target date

## Fix

Thread `edition_for` (the edition's target trading day) through the call chain:
1. Add `edition_for?: string` parameter to `buildDeterministicEditionPlays` params
2. Add `edition_for?: string` parameter to `buildRescuePlays` params
3. Add `asOfEtYmd?: string` parameter to `pickChainContract()` signature (last parameter, optional)
4. Update `pickChainContract()` to use: `const today = asOfEtYmd ?? todayEtYmd();`
5. Pass `params.edition_for` to all `pickChainContract()` calls within deterministic-edition.ts
6. Update `generateEditionPlays()` signature to accept `edition_for?: string`
7. Pass through to `buildDeterministicEditionPlays` and `buildRescuePlays` calls
8. Update `edition-builder.ts` to pass `editionFor` to `generateEditionPlays()`
