| **Item 1 — unqualified annual refund guarantee** | The homepage's "Premium · Yearly" pricing card said "7-day money-back guarantee · cancel anytime" with no qualifier. The refund is annual-plan-only — `/pricing` and `/refund-policy` both state monthly billing is non-refundable for the current cycle — so a visitor scanning the homepage card in isolation could reasonably read it as a platform-wide guarantee. `/pricing`'s own card already scopes this correctly (a "Premium · Yearly" heading directly above the same trust line, plus its own "Full refund policy →" link); the homepage card had neither. Fixed by prefixing the line with "Annual plan:" and adding a "Refund policy →" link beside it (reusing the existing `hero-cred-link` small-link style already used elsewhere on the page, rather than nesting the link inside the `<p className="trust">` — that would have broken an existing regression test, `RedesignHome.pricing.test.ts`, whose `[^<]*` capture assumes trust lines are plain text with no nested tags; keeping the link as a sibling element preserves that invariant instead of weakening the test). |
