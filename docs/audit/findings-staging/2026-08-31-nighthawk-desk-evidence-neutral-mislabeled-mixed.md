## 2026-08-31 — [FIX, P3 UI accuracy] Night Hawk desk-evidence chip labels NEUTRAL reads as "MIXED" — FIXED

> **kind:** `FINDING`

| Field | Detail |
|---|---|
| **Context** | Live UI audit of Night Hawk against `docs/audit/NIGHTHAWK-3RAIL-REDESIGN.md` (the X Ads Manager–referenced reskin brief), triggered by a request to verify the recent UI changes against that spec end-to-end. Captured live desktop (1440×900) and mobile (430×932) screenshots of `/nighthawk` via `proxy-browser.cjs` against production, 2026-08-31 ~09:45 ET. |
| **Root cause** | `DeskEvidenceStack.tsx` and `ThesisRankCard.tsx` — the "WHY WE PICKED IT" / desk-evidence panels rendered on every 0DTE play's detail view — each independently defined a local `statusLabel()` mapping the `DeskEvidenceStatus` value `"neutral"` to the display string `"mixed"`. But `"neutral"` is produced by `desk-evidence-lines.ts` from at least three distinct, non-equivalent situations: (1) an explicit upstream `bias === "mixed"` reading (genuinely mixed evidence), (2) a rail score that's below the confirm floor but not opposing (`railAligned()`, `floor-15 <= score < floor`) — i.e. simply inconclusive, not conflicting, and (3) a structural non-confirm (e.g. `gamma === "short"` against a `long` thesis — not aligned, but also not a contradiction). Live evidence: SNXX's THERMAL line read "short-gamma · above 15 call wall" (case 2/3, no upstream bias field at all) yet rendered the "MIXED" chip — the same word a genuinely conflicting dark-pool/premium bias would show. This is exactly the NO DATA / NEUTRAL / OPPOSED conflation the redesign brief's §1 "Visual intelligence" section explicitly names as a distinction that must not be collapsed (`docs/audit/NIGHTHAWK-3RAIL-REDESIGN.md` line ~107-111) and that this repo's Largo product contract treats as a first-class discipline elsewhere (never let absence/inconclusiveness read as a stronger claim than it is). |
| **Fix** | Extracted a single tested `deskEvidenceStatusLabel()` into `src/lib/zerodte/thesis/desk-evidence-lines.ts` (the same module that already defines `DeskEvidenceStatus` and produces the underlying reads) mapping `"neutral"` → `"neutral"` instead of `"mixed"` (`"aligned"`/`"opposed"`/`"unavailable"` labels unchanged). Both components now import and alias it (`deskEvidenceStatusLabel as statusLabel`) instead of each carrying its own duplicated switch — removes the duplication as well as the mislabel. |
| **What was deliberately NOT changed** | The underlying `DeskEvidenceStatus` producer logic (`biasStatus`, `railAligned`, the per-desk `format*Line` functions) — none of those are wrong; a genuinely mixed upstream bias reading still correctly collapses into the `"neutral"` status today (`biasStatus`: `if (bias === "mixed") return "neutral";`), which is a legitimate design choice already documented at that call site. Only the DISPLAY LABEL for the neutral status changed, not which underlying reads produce it. CSS classes (`is-neutral` / `text-sky-200`) were already correctly neutral-toned, not mixed-toned — no visual/color regression, text-only fix. |
| **Evidence** | Live production API dump of `GET /api/market/zerodte/board` (2026-08-31 ~09:45 ET, via `scripts/audit/lib/audit-auth-fetch.mjs`) confirmed SNXX's THERMAL desk-evidence line had no upstream bias field and status `"neutral"` purely from `railAligned()`'s below-floor branch, while the live-rendered desktop screenshot showed its chip as "MIXED". `src/lib/zerodte/thesis/desk-evidence-lines.test.ts` — new test `deskEvidenceStatusLabel: neutral reads 'neutral', not 'mixed'` asserts all four label mappings. Git-stash red/green proof: with the fix stashed, the new test fails (`deskEvidenceStatusLabel is not a function` — pre-extraction); with it restored, 5/5 pass. `npx tsc --noEmit` clean (Node 20.20.2). |
| **Blast radius** | Two component files (`DeskEvidenceStack.tsx`, `ThesisRankCard.tsx`) both consuming the same new shared function — the exact "duplicated logic in a second file" case this repo's PR write-up policy calls out to catch. Pure display-text change, no data/gating/P&L logic touched, no other consumer of `DeskEvidenceStatus` affected. |
| **Status** | FIXED — merged pending CI. |
