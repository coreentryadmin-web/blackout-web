## 2026-08-31 — [MEASUREMENT, P3 research] Vector pick self-reported confidence (tier/grade/conviction) shows NO positive correlation with outcome — preliminary, insufficient data — INSUFFICIENT DATA

> **kind:** `FINDING`

| Field | Detail |
|---|---|
| **Context** | User asked "what should we be doing to get 100%+ winner plays" on both 0DTE and Vector. Investigated whether Vector's own pick-time confidence signals (`tier`, `play.grade`, `play.conviction`) predict outcome, using the ONLY data the `vector_pick_leaders` tracker has — it went live 2026-08-28 and this is its 2nd trading session. |
| **Method** | Pulled `GET /api/market/vector/pick-closures/board?session_date=<d>` for every date with rows (2026-08-28: 77 rows, 2026-08-31: 326 rows — every other date checked in between, including 08-20/08-21/08-24/08-25/08-26/08-27/08-29, returned 0 rows, confirming the tracker has no earlier history to query). Bucketed `premium_pct_from_entry` by `pick_context.tier`, `play.grade`, `play.conviction` (banded), `pick_context.rank`, `pick_context.role`, `play.bias`. |
| **Result (n=403, 2 sessions only)** | Three independent confidence signals all point the SAME direction, against expectation: **elite tier** (n=10) avg **-9.4%**, 0% hit a 50%+ winner vs standard tier (n=393) avg -0.6%, 2.0% winners. **Grade A** (n=52) avg **-3.3%** vs grade B (n=176) avg -0.8% (best of the three). **Conviction 70+** (n=72) avg **-3.2%** vs the 40-54 band (n=136) avg +0.1% (best). `rank` behaves correctly (rank=1 beats rank=2/3). `role=primary-long` (n=60) stands out positively: avg +3.4%, 6.7% hit-rate — the one structurally good cut in this sample. |
| **Why this is NOT a finding to act on** | n=403 across exactly 2 sessions is far below the bar this repo's own calibration work uses elsewhere (e.g. the G-17 gate's n=152/90-day measurement, `cortex-oppose-magnitude-ab.mjs`'s n=341/90-day). Two days can trivially be regime-specific (a Friday chop session + one range-regime Monday). Tier/grade/conviction assignment could also be confounded with setup aggressiveness (elite/A-grade setups may systematically target bigger, more volatile moves that swing harder both directions) rather than the confidence label itself being wrong. |
| **What was deliberately NOT changed** | No weighting, tier, or ranking logic touched. This is a preliminary read only. |
| **Recommendation / re-run trigger** | Let `vector_pick_leaders` accumulate 2-3 more weeks of real sessions, then re-run this exact bucket breakdown (same query shape, no new tooling needed — see Method above) with a real sample before drawing any conclusion or touching Vector's conviction/tier scoring. |
| **Status** | INSUFFICIENT DATA — re-run once the tracker has ~15-20 sessions of history (mid-to-late September at current pace). |
