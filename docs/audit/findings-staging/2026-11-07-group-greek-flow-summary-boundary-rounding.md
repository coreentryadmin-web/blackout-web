## 2026-11-07 — `summarizeGroupGreekFlow`'s headline renders "1000K" instead of "1.00M" at the K→M unit boundary — FIXED

| **Status** | Fixed |
|------------|-------------------|
| **Symptom** | `summarizeGroupGreekFlow()` in `src/lib/group-greek-flow-summary.ts` — the shared UW group-flow (mag7/sector) dealer-delta headline builder, consumed by `spx-desk.ts`, the Night Hawk Cortex/market-wide reads, and `run-tool.ts`'s Largo tool surface — renders a net delta in `[999_500, 999_999]` (and the mirrored negative range) as `"1000K"` instead of promoting to `"1.00M"`, e.g. a headline reading `"Mag7 dealer delta flow supportive — net 1000K delta"` instead of `"...net 1.00M delta"`. |
| **Root cause** | The M-vs-K branch decision (`Math.abs(netDelta) >= 1_000_000`) runs on the raw value, before any rounding, while the K branch's own display (`Math.round(netDelta / 1000)`) rounds to the nearest whole K afterward. For `netDelta` in `[999_500, 999_999]` (or `[-999_999, -999_500]`), the raw magnitude is `< 1_000_000` so the code takes the K branch, but `Math.round(netDelta / 1000)` rounds to `1000` (or `-1000`) — a four-digit "K" label that has silently crossed its own unit boundary. This is the exact same unit-boundary rounding bug already fixed, independently, in `src/lib/fmt-money.ts`'s `fmtPremium` (K→M and M→B), `src/lib/thermal-discord-card.ts`'s `fmtCompactHeatMoney`, `src/lib/darkpool-discord-format.ts`'s `fmtShares`, `src/lib/discord-context-enrichment.ts`'s `formatAdvShareLabel`, and `src/features/helix/lib/helix-flow-format.ts`'s `fmtOi` (the latter fixed earlier this session) — each carries a comment pointing to "the same bug shape" in a sibling, but `summarizeGroupGreekFlow`'s `deltaM` formatting was never checked against it and had no regression test covering the boundary. |
| **Evidence** | `npx tsx --experimental-test-module-mocks --test src/lib/group-greek-flow-summary.test.ts` — before the fix (verified by `git stash`-ing just the source change and re-running against the new tests): `summarizeGroupGreekFlow(..., dir_delta_flow: "999600")`'s headline contains `"net 1000K delta"` (new assertion expecting `/1\.00M/` fails, 2 of 11 tests RED — the positive and the sign-preserving negative case). After the fix: all 11 tests pass, including the new boundary cases and an unaffected sub-boundary control (`~308K`, unchanged). |
| **Blast radius** | `summarizeGroupGreekFlow` has one formatting call site inside the function itself (the `deltaM`/`headline` computation), but the function's return value and headline string are consumed by three callers: `src/features/spx/lib/spx-desk.ts`, `src/features/nighthawk/lib/ticker-greek-flow-summary.ts` / `market-wide.ts` / `format.ts` (Night Hawk Cortex market-wide read), and `src/lib/largo/run-tool.ts` (the Largo tool surface) — all of which display or forward the `headline` string verbatim, so the fix benefits every consumer without touching any of those files. No other function in the repo duplicates this exact `Math.abs(x) >= 1_000_000 ? ...M : Math.round(x/1000)+K` shape (checked via a targeted grep); the remaining sibling instances of the broader pattern found this round were already fixed in a prior session or live in excluded domains (SPX/zerodte/Night Hawk/Largo/Helix-Vector-Thermal-Meridian component+lib surface, Discord notification pipeline), per this round's scope rules. |
| **Fix rationale** | Applied the identical round-first-then-promote guard already used by the five sibling formatters named above: compute `absDelta = Math.abs(netDelta)`, and promote to the M branch whenever either the raw magnitude already clears 1,000,000 OR `Math.round(absDelta / 1000) >= 1000` (the value that would otherwise round into an overflowed 4-digit K label). Divides the original, signed `netDelta` (not `absDelta`) by `1_000_000` for the M branch so the existing sign-handling (`"-1.00M"` for a negative boundary value) is preserved unchanged, and left the K branch, the `bias` threshold, and every other computation in the function untouched. |
| **Verify** | `npx tsx --experimental-test-module-mocks --test src/lib/group-greek-flow-summary.test.ts` (new assertions pass, 11/11); `npx tsc --noEmit` clean; full `npm test` run clean (18135 pass / 0 fail / 3 skipped, see PR). |
