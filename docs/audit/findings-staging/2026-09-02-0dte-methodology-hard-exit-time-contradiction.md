## 2026-09-02 — [P1, data correctness/trust] Public /methodology page quoted two different 0DTE hard-exit times (15:50 vs 15:30) for the SAME mechanical grading rule — plus an unrelated live merge-conflict marker found in the same sweep — FIXED

| Field | Value |

| **Reported by** | User, live QA of `/methodology` (the public track-record/grading-methodology page). |
| **The contradiction** | `/methodology` renders `MethodologyContent`'s `ZD_DETAIL` ("...plan grade (−50% / +100% / **15:50** ET)..."), then immediately below it `ZERODTE_RECORD_METHODOLOGY` from `src/lib/zerodte/record.ts` ("...The fixed -50%/+100%/**15:30**-ET plan grade..."), then `TRACK_RECORD_METHODOLOGY` from `src/lib/track-record-page.ts` ("...hard exit **15:50** ET..."). | **Blast radius confirmed by full-repo grep** | `record.ts` (live string + 4 stale internal comments), `track-record-page.ts` (2 stale comments; live `TRACK_RECORD_METHODOLOGY` string was already correct), `MethodologyContent.tsx` (`ZD_DETAIL`, already correct but hardcoded), `article-faqs.ts` line 575 (0DTE Command guide FAQ, user-facing), `articles.ts` lines 1633/2101/2211/2455/2457 (article body prose, user-facing on `/learn/night-hawk-0dte-command-guide`, `/learn/theta-decay-options-explained`, `/learn/pin-risk-options-explained`).
