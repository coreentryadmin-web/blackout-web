# Off-Page SEO / Backlink Strategy

Off-page SEO — backlinks, external authority, co-marketing — is fundamentally **not a code
task**. No script, PR, or audit can acquire a backlink; that requires a human doing outreach,
building a relationship, or a creator choosing to link out. This doc is the concrete strategy
and materials for a human to execute, not a promise of specific placements. It does not name
specific outside websites/creators as confirmed targets — this is a starting research list by
category, not verified outreach relationships.

**Read this alongside `docs/marketing/SEO-GROWTH.md` first** — several rows there already cover
adjacent ground and the decisions already made:
- Referral/affiliate program: **dropped** (owner decision 2026-08-07) — Whop already runs one.
  Don't rebuild this; use the existing mechanic (see "Creator co-marketing" below).
- `/vs/others` comparison page: shipped, generic (no named competitor).
- `/tools/gamma-snapshot`: shipped, the site's one real public lead-magnet/linkable asset.

## What BlackOut actually has to offer a linker (be honest about this — it's short)

1. **`/tools/gamma-snapshot`** — free, no-signup, live dealer-gamma/wall levels for SPX/SPY/QQQ.
   This is the one genuine "linkable asset" on the site right now: something a third party can
   point to and get real, live value delivered to their own readers without friction. Any outreach
   pitch should lead with this, not with the paid product.
2. **The `/learn` content library** — 45 articles + 7 guides, genuinely substantive (not thin
   SEO filler), on dealer gamma / GEX / 0DTE mechanics. Worth citing/linking to as a reference,
   the way a finance blog cites Investopedia for definitions — except this content is more
   current and options-flow-specific than the generic finance-education sites that currently
   rank for these terms.
3. **The Whop affiliate program** — already live, already the correct mechanic for creator
   co-marketing (per the SEO-GROWTH.md decision above). This is a *paid-conversion* channel, not
   a backlink channel per se, but creators who join it have a direct incentive to link/mention
   the platform, which is a legitimate secondary path to real backlinks — worth mentioning in any
   creator outreach pitch as the "and there's a commission if your audience converts" close, not
   the opener.

## What BlackOut does NOT yet have (be honest about the ceiling)

No public track record (walked back to admin-only, confirmed intentional, see SEO-GROWTH.md #2),
no press coverage, no notable named customers/testimonials, no research/data studies published,
no conference talks or podcast appearances on record. This caps what a cold-outreach pitch can
credibly claim right now — lead with the free tool and the content depth, not with authority the
site doesn't have yet.

## Target categories (research starting points, not a verified contact list)

Categories a human should research and vet real, current contacts for — none of the following
are claims that BlackOut has an existing relationship with any specific site:

1. **Finance/trading education blogs and newsletters** that already write about options
   mechanics, 0DTE, or dealer positioning — the natural audience for both the free tool and the
   `/learn` content. A genuinely useful pitch to this category: "we built a free live gamma-flip
   tool, want to feature/embed it" rather than a generic "please link to us."
2. **Options-trading communities** (Reddit's r/options, r/thetagang, r/SPX, relevant Discord
   servers) — not a backlink source in the traditional sense (most carry `nofollow` and heavily
   moderate self-promotion), but real traffic + brand-recognition source that indirectly drives
   organic search volume and natural link mentions over time. Participate as a genuine
   contributor first; a promotional-only presence gets banned and wastes the effort.
3. **Fintech/trading-tool directories and roundups** ("best options flow tools", "best 0DTE
   tools" listicles) — the standard SaaS-directory play. Low individual link value each, but
   cumulative and low-effort once the pitch template exists.
4. **Trading-education YouTube/Substack creators** already covered by the Whop affiliate
   program's natural target list — the affiliate program IS the outreach mechanic here; a
   separate backlink ask on top of an affiliate pitch is redundant, fold them into one outreach.
5. **Guest-post / contributor opportunities** on established finance-education sites (Investopedia
   contributor network, Seeking Alpha, TradingView's ideas/education section) — highest individual
   link value, highest effort (real editorial process, needs a genuinely original angle, not
   reused `/learn` content verbatim).

## Outreach pitch template

Use for categories 1, 3, and 5 above (not for community participation in category 2 — that
needs to be organic, not a template message).

> Subject: Free live gamma-flip tool for [SITE NAME]'s readers
>
> Hi [NAME],
>
> I noticed [SITE NAME] covers [SPECIFIC RELEVANT TOPIC — reference something real they
> published]. We built a free, no-signup tool that shows live dealer gamma flip, call wall, and
> put wall levels for SPX/SPY/QQQ — the same positioning data professional desks watch, updated
> every few minutes: https://blackouttrades.com/tools/gamma-snapshot
>
> No catch — it's genuinely free, no email required. If it'd be useful to link/embed for your
> readers, happy to answer any questions about the methodology. We also have a deeper explainer
> library on dealer gamma mechanics if useful context: https://blackouttrades.com/learn
>
> [Only include if applicable to this recipient — creators with an audience, not directories/blogs:]
> Separately, we run an affiliate program through Whop if a partnership makes sense down the line
> — no pressure either way, wanted to share the free tool regardless.
>
> Thanks,
> [NAME]

## What this doc is not

Not a guarantee of results, not a list of confirmed placements, not a substitute for a human
doing the actual relationship-building. The honest ceiling: off-page authority for a ~2-week-old
domain builds over months, not days, and no amount of tooling changes that — this doc exists so
the next time-investment in this area starts from a real plan instead of a blank page.
