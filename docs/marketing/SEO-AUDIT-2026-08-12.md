Full-site SEO visibility audit for blackouttrades.com. Validates public indexability,
metadata completeness, crawl surfaces, and internal linking.

## Findings fixed in this PR

1. **Canonical leak on noindex pages** — root layout sets homepage canonical; app pages using
   `noindexPageMetadata` inherited it. Fixed: optional `path` param sets self-referential canonical.
2. **`/account` inconsistent robots** — had `index: false` but not `follow: false`. Now uses
   `noindexPageMetadata`.
3. **Admin sub-routes missing noindex** — `/admin/users`, `/admin/largo-answer-preview` had no
   robots meta (mitigated by `/admin` disallow + auth, but defense in depth added).
4. **Orphan SEO pages** — `/vs/others` and `/tools/gamma-snapshot` were slow to index (GSC Aug 2026)
   partly due to weak internal linking. Added footer + nav links sitewide.
5. **Default OG image 394KB PNG** — switched default to `og-image.webp` (130KB) in layout metadata,
   Organization JSON-LD, and Article fallbacks. PNG kept as fallback asset.
